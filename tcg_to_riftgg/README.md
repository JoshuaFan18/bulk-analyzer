# Purpose
The purpose of this project is to take TCGplayer exported CSVs of Riftbound cards and convert them into formats acceptable by Riftbound.gg
## Acceptable formats

1. DotGG (Preferred): `CardID, Normal Count, Foil Count, Name, Set`
    * Example: OGN-001, 1, 0, "Blazing Scorcher", "Origins"
2. Legacy: Normal Count, Foil Count, CardID
    * Example: 1, 0, OGN-001

## ID Conventions
`Vendetta = VEN`  
`Unleashed = UNL`  
`Spiritforged = SFD`  
`Origins = OGN`  
`Origins Starter = OGS`
